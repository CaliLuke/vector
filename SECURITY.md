# Security policy

Report Vector vulnerabilities through [GitHub private vulnerability reporting](https://github.com/CaliLuke/vector/security/advisories/new).
Do not put exploit details, credentials, or personal data in a public issue.

Include the affected revision, reproduction steps, expected behavior, actual behavior, and security impact.
Use a disposable instance and synthetic data. Do not test against another operator's deployment without authorization.

The maintainer coordinates fixes and disclosure through the private report. No response-time guarantee or bounty program is offered.
Vector security reports belong to this repository. Plane's security team does not maintain Vector.
